## 1. 背景与目标

### 1.1 背景

内容出海团队需要把中文小说/剧本改编为面向海外市场的短剧剧本格式，并做文化/世界观适配。市场上存在同类「上传 → AI 处理 → 编辑 → 导出 + 积分订阅」产品；本项目做**自有品牌完整同类产品**，不复制竞品品牌、文案、样例与视觉素材。

### 1.2 产品目标（MVP）

在 Demo 模式下跑通完整闭环：

1. 用户注册/登录  
2. 上传原文（PDF / DOCX / TXT）  
3. AI（或 Demo 假数据）产出短剧剧本稿  
4. 在线编辑  
5. 导出文件  
6. 积分扣减与用尽阻断  

真实支付（Creem 等）留到 Demo 验证通过后再接。

### 1.3 非目标（V1 明确不做）

- 复制或仿写竞品（含 StoryProTool 等）的文案、样例对、Logo、页面视觉资产  
- 视频配音、对口型、成片渲染  
- 多人实时协作审稿、复杂权限体系  
- 通用文生图 / 文生歌平台  
- 真实收款上线（本阶段仅 Demo 发积分）

## 2. 用户与场景

### 2.1 主要用户

| 角色 | 描述 | 核心诉求 |
|------|------|----------|
| 内容出海编剧/制片助理 | 把中文 IP 改成海外短剧可拍剧本 | 快、格式对、术语一致、能改稿导出 |
| 独立工作室（1–2 人） | 小团队试水出海改编 | 订阅成本可控、积分可预期 |

### 2.2 关键场景

- 上传一部中文小说章节或剧本，一键得到英文（默认）短剧分场剧本草稿  
- 校对角色名、术语表，在编辑器里改完导出给合作方  
- Free 额度试跑；满意后再考虑订阅（正式付费阶段）

## 4. 功能需求

### 4.1 营销站点

- 路径：`/zh`、`/en`（至少首页、定价、登录入口）  
- 内容：价值主张、四步流程、功能点、定价表；**原创文案**  
- 页脚：Terms / Privacy / Acceptable Use（短文即可）

### 4.2 账号

- 邮箱 + 密码，或 Magic Link（二选一实现即可，推荐邮箱密码以降低 Demo 依赖）  
- 会话持久化；未登录访问 App 区跳转登录  

### 4.3 任务（Job）

**创建**

- 上传文件：PDF / DOCX / TXT，单文件 ≤ 20MB  
- 选项：目标语言（默认 EN）、是否角色映射、是否世界观/文化适配、输出格式偏好  
- 创建前校验积分余额 ≥ 预估消耗；不足则拒绝并提示升级/Demo 补积分  

**处理**

- 状态机：`queued` → `processing` → `succeeded` | `failed`  
- 成功后写入可编辑正文 + 元数据（角色表、术语表等，可 JSON）  
- 失败保留错误信息，已预扣积分策略见 5.2  

**编辑与导出**

- 富文本或 Markdown 编辑器均可；须能保存  
- 导出 PDF / DOCX / TXT；导出本身不额外扣大额积分（或固定小额，需在技术文档写死）  

### 4.4 AI 能力（产品语义）

管线步骤（逻辑顺序）：

1. 解析上传文本  
2. 分场 / 大纲  
3. 角色映射 + 术语一致性  
4. 世界观 / 文化适配（默认面向英语市场）  
5. 输出短剧剧本格式正文  

无 LLM Key 时：使用内置种子任务与假输出，保证 UI 可演示。

### 4.5 积分与套餐（产品侧）

| 套餐 | 标价（对外展示） | 积分 | 说明 |
|------|------------------|------|------|
| Free | $0 | 一次性约 150,000 | 注册即发；核心改编 |
| Pro | $29.99/月 | 约 900,000/月 | 全流程 |
| Business | $59.99/月 | 更高额度 + 多世界观对比入口 | 团队向展示 |

**硬规则（不可破）**

1. 积分用尽后禁止创建新消耗型任务（硬停）  
2. 禁止静默超额调用上游 LLM  
3. UI 常显剩余积分  
4. Demo 阶段：管理员/用户可在账户页「领取 Demo 积分」或切换「模拟 Pro」；不产生真实扣款  

积分与美元成本的换算公式、安全垫见《技术文档》；上线前须用实测 p50/p90 成本校准数字。**当前标价与积分数为占位，未经实测校验前不得宣传为最终定价。**

### 4.6 账户页

- 显示：邮箱、当前套餐（含 Demo 模拟态）、剩余积分、最近任务  
- Demo：按钮「补充 Demo 积分」「模拟订阅 Pro/Business」  
- 正式支付入口：占位文案「即将开放」，不接真支付

## 5. 业务规则

### 5.1 文件与安全

- 仅接受声明的 MIME/扩展名；病毒扫描可后置  
- 用户内容私有；不用于对外展示样例（除非用户明确授权）  
- Acceptable Use：禁止违法、侵权上传；产品方可拒绝处理  

### 5.2 积分扣减

- **预估 → 预留/预扣 → 完成按实扣 → 差额退回**（推荐）  
- 若实现简化：创建时按档位固定扣费；失败退回 80%（比例写死并在 UI 说明）  
- 具体算法以《技术文档》为准，产品与技术必须一致  

### 5.3 品牌与合规

- 品牌名：DramaForge  
- 不得使用竞品商标、域名暗示隶属关系  
- 营销对比仅可做品类级描述，不做诽谤式点名抄袭
